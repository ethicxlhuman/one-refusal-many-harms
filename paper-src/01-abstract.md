# Abstract

Security researchers want an open model that will answer hacking questions but still refuse to help with biological weapons, violence or child abuse. A popular way to remove refusals is "abliteration": find the direction inside the model that makes it say no, and erase it. I tested whether abliteration can remove only the cyber refusals from Gemma 4 31B-it. Before editing anything, I measured that the model's cyber refusal direction points almost the same way as its general refusal direction (cosine 0.67 to 0.86 in the later two-thirds of the network). Both methods in the Heretic 2.1.0 tool then failed, in opposite ways. One (ARA) answered 89% of 93 held-out cyber requests, but it also started answering half of the bio/chem requests the original model refused. The other (Abliteration) kept 94% of the original refusals but answered only 49% of cyber requests. I then removed only the part of the cyber direction that is not shared with general refusal. The model still refused 53 of 60 cyber requests (the original refused 56), even at three times the normal edit strength. On this model, cyber refusals run through the same machinery as every other refusal, so erasing a direction cannot unlock cyber alone. I show real model inputs and outputs for each case, and the evaluation checks that exposed the bio/chem leak, which a single cyber score would have hidden.
